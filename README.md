# NosChat - AI 聊天应用前端

这是一个基于 Vite + Vue 3 的 AI 聊天应用前端演示。应用展示了完整的聊天界面和交互逻辑，暂未集成实际 AI 能力。

## 功能特性

- 🎨 **现代化聊天界面**：采用渐变背景、毛玻璃效果和流畅动画
- 💬 **多对话管理**：支持查看历史对话、创建新对话
- 📱 **响应式设计**：适配桌面端和移动端
- ⌨️ **智能输入框**：支持快捷键、自动调整高度、快捷回复建议
- ⚡ **实时交互反馈**：打字状态指示、发送动画、消息动画
- 🎯 **离线演示模式**：包含完整的模拟数据，无需后端即可运行

## 技术栈

- **框架**：Vue 3 (Composition API)
- **构建工具**：Vite 5
- **样式**：原生 CSS + CSS 变量
- **交互**：Vue 响应式系统
- **设计**：现代化 UI 设计，无 UI 库依赖

## 快速开始

### 前端开发
1. **进入前端目录**
   ```bash
   cd web
   ```

2. **安装依赖**
   ```bash
   npm install
   ```

3. **开发模式**
   ```bash
   npm run dev
   ```
   应用将在 http://localhost:3000 启动

4. **构建生产版本**
   ```bash
   npm run build
   ```

5. **预览构建结果**
   ```bash
   npm run preview
   ```

## 核心组件说明

### ChatSidebar.vue
- 显示历史对话列表
- 支持新建对话
- 显示对话预览和未读状态
- 状态指示器

### ChatMessages.vue
- 显示对话消息记录
- 区分 AI 和用户消息
- 打字状态指示器
- 空状态和快捷建议

### ChatInput.vue
- 智能消息输入框（自适应高度）
- 快捷键支持（Enter 发送，Shift+Enter 换行）
- 快捷操作按钮
- 字符计数和验证

## 开发指南

### 代码结构
- **组件化设计**：每个功能模块都是独立的 Vue 组件
- **响应式数据**：使用 Vue Composition API 管理状态
- **样式隔离**：使用 CSS Scoped 避免样式冲突
- **模拟数据**：开发阶段使用本地模拟数据

### 添加新功能
1. 在 `src/components/` 创建新组件
2. 在 `App.vue` 中注册和使用
3. 更新模拟数据和状态管理
4. 添加对应的样式

### 集成真实 API
1. 创建 API 服务层
2. 替换模拟数据为真实调用
3. 添加加载状态和错误处理
4. 实现消息持久化
